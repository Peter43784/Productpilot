# NPS deep dive — Q1 2026 (survey: Jan 1 – Mar 31)

NPS: 31 (n=412) · Promoters 42% · Passives 31% · Detractors 27%

Top detractor drivers (clustered):
1. Month-2 value cliff — 61 detractors cite unclear value after the trial month.
2. First-run confusion — 44 cite overwhelming setup.
3. Broken legacy CSV export — 33 cite finance workflows.
4. Missing Slack/push alerts — 27 cite ops workflows.

Top promoter drivers:
- Fast, reliable reporting once activated.
- Responsive support (esp. GDPR questions).

Recommendation for Q3: activation metric instrumentation + month-2 onboarding check-in.
